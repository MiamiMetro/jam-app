# Jam Legal Release Pack

This folder is the source copy for the public legal pages linked from the app. The app defaults to the GitHub `blob/main/docs/legal/...` URLs. Before App Store submission, prefer publishing prettier public pages and configuring:

- `VITE_TERMS_URL` / `EXPO_PUBLIC_TERMS_URL`
- `VITE_PRIVACY_URL` / `EXPO_PUBLIC_PRIVACY_URL`
- `VITE_KVKK_URL` / `EXPO_PUBLIC_KVKK_URL`
- `VITE_SUPPORT_URL` / `EXPO_PUBLIC_SUPPORT_URL`
- `VITE_PRIVACY_CHOICES_URL` / `EXPO_PUBLIC_PRIVACY_CHOICES_URL`
- `VITE_OPEN_SOURCE_URL` / `EXPO_PUBLIC_OPEN_SOURCE_URL`

These are product drafts, not legal advice. Have counsel review the final public text before release.
