# App Store Privacy Answers Draft

Use this as the App Store Connect data map. Final answers must match the actual production services and SDKs.

## Data Linked to the User

- Contact Info: email address.
- User ID: account/auth identifiers and profile ID.
- User Content: posts, comments, DMs, room messages, profile text, communities, rooms, uploaded audio, avatars, banners.
- Audio Data: audio uploads and recordings where enabled.
- Identifiers: session/auth identifiers and device/app identifiers if generated by providers.
- Usage Data: feature usage and moderation/safety actions if logged.
- Diagnostics: crash or performance data if a diagnostics service is enabled.

## Tracking

Do not mark tracking unless the production app or SDKs use data for cross-app/site tracking or advertising attribution.

## Required Public URLs

- Privacy Policy URL.
- Support URL.
- Optional Privacy Choices URL.
