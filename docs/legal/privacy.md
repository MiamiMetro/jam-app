# Jam Privacy Policy

Last updated: 2026-05-14

Jam collects only the data needed to run a social music app.

## Data We Process

- Account data: email address, authentication identifiers, session data.
- Profile data: username, display name, avatar, banner, bio, instruments, genres, friend graph, block list.
- User content: posts, comments, direct messages, room messages, communities, rooms, band listings, and uploaded audio.
- Safety data: reports, moderation status, blocked users, deleted or anonymized account state.
- Technical data: device/app information, IP-derived network data handled by service providers, logs, upload metadata, and diagnostics if enabled.
- Local app data: theme, navigation state, update state, auth/session cookies, and secure auth tokens stored on the device.

## Purposes

We use data to provide accounts, profiles, feeds, messaging, audio upload/playback, communities, jam rooms, safety tools, abuse prevention, support, security, and app updates.

## Service Providers

Jam may use providers such as Convex, Better Auth, object/media storage, Apple, Google, Expo, GitHub Releases for desktop updates, and hosting/CDN providers. Provider use depends on the released build configuration.

## User Choices

Users can edit profile data, delete posts/comments/messages where supported, block users, report content, and delete their account from settings. Privacy/data requests should be sent through the privacy choices URL or support contact configured for the released app.

## Retention

Some records may remain after account deletion where required for safety, security, legal obligations, abuse prevention, or preserving conversation integrity. Public identity fields are anonymized when the account deletion flow runs.
